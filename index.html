Web 4.0 · Contrivance Engineering

The article series

A CMS was only ever two jobs — store content with structure and give non-technical people a way to change it. These articles show web developers how to replace it with a smaller, cleverer mechanism: Next.js + GitHub + Vercel, with an AI assistant as the content manager. Content management was never about the dashboard; it was always the loop — intent → change → review → publish — rebuilt from a chat, a branch, a preview URL, and a merge.

Start with your platform

  1. Goodbye WordPress
    Replace wp-admin with an AI assistant. The flagship migration playbook: export, content layer, redirects, dev/staging/prod branches, and the AI content workflow.
  2. Goodbye FTP
    Unfreeze static HTML sites. No database to escape — migrate one page at a time and install a CMS where none existed.
  3. Goodbye App Stack
    Unbundle Shopify: headless Next.js storefront on Vercel, Shopify kept for checkout, AI assistant as merchandiser.
  4. Goodbye Lock-in
    Escape Wix. No export exists, so the AI jailbreaks the content by crawling the live site — then you own everything.
  5. Goodbye Template Cage
    Keep the beauty, lose the cage. Pixel-faithful rebuilds, galleries as real components, AI content ops.
  6. Goodbye Webflow
    Graduate to code you own. Code export maps to Next.js components, Collections become Markdown, no seat taxes.
Written with an AI assistant. The series practices what it preaches.
